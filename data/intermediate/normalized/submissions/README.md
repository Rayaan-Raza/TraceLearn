## Rules

1. `tracelearn_label` is null in every row. No source supplies misconception labels.
2. `label_status` is `source_label` only when the source gave a verdict.
3. `correct` follows the source verdict only. It is not a TraceLearn judgement.
4. Code stays in the raw tree. `source_code_path` points at it. Never rewrite it.
5. Do not convert a source verdict into a misconception label.
